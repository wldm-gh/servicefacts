Service Facts

Open vocabularies for the facts buyers ask about professional services.

schema.org describes businesses well, but it cannot say many of the facts that decide a buyer's choice, such as who a law firm acts for or how long a legal deadline is. Service Facts adds a small, checked set of terms for each industry, on top of schema.org.

Every term has a permanent ID under https://w3id.org/servicefacts/. The ID never changes, even if these files move.

Rules

  • Standard schema.org first. A new term only where schema.org has no home.
  • A term ID never changes and is never deleted.
  • Pages write the prefix inline. They never load a remote context file.
  • Every fact in the markup is also written as visible text on the page.

Service Facts / Legal services

Legal services vocabulary v0.1 draft

Version 0.1, 2026-10-20. Namespace https://w3id.org/servicefacts/legal#, prefix legal:. Files: JSON-LD · Turtle · frozen copy of v0.1

Start here. schema.org cannot say some things buyers ask a law firm: who the firm acts for, how it charges, which process and tribunal a matter goes through, which law governs it, and the legal time limits. This vocabulary adds 16 properties, 1 class and 5 value lists for those facts. Use standard schema.org first. Use these terms only where schema.org has no home.

Status: draft. Version 0.x can still change. Term IDs never change and are never deleted. Version 0.1 was built for Australian building and construction law.

How to use it on a page

  1. Write the prefix inline in @context. Never load a remote context file: if it cannot load, JSON-LD processing stops.
  2. Write every fact as visible text on the page too, for example in a "Key facts" table. Search engines and AI engines quote text, not hidden markup.
  3. Where a standard schema.org property can carry part of the fact, publish it as well (see "Also publish as").
{
  "@context": ["https://schema.org", {"legal": "https://w3id.org/servicefacts/legal#"}],
  "@type": "Service",
  "name": "Security of payment claims",
  "audience": {"@type": "BusinessAudience", "audienceType": "Subcontractors"},
  "legal:actsFor": {"@id": "https://w3id.org/servicefacts/legal#PartyRoles-subcontractor"},
  "legal:disputeProcess": {"@id": "https://w3id.org/servicefacts/legal#DisputeProcesses-adjudication"}
}

Profile notes in the file

The vocabulary file uses these terms to describe its own terms. They never go on a page.

TermMeaning
legal:priorityHow much buyers need this fact: High, Medium or Low. High means asked often and it decides the choice.
legal:moduleWhich part of the profile the term belongs to: core (every firm) or a practice module such as construction.
legal:answersQuestionThe buyer question, in plain words, that this fact answers.
legal:visibleTextRequiredTrue when the fact must also be written as visible text on the page. It always is for this profile.
legal:priorityEvidenceWhere the priority comes from, and how it will be measured.
legal:dualPublishAsThe standard schema.org property that should carry the same fact as well, so engines that ignore custom terms still get it.
legal:propertyIndexCounts of the terms in this file.
